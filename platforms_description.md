## 2.2 Platforms

### 1. Visual Studio Code (v1.85+)
**Figure 1: Visual Studio Code**  
Visual Studio Code (VS Code) is a lightweight yet powerful source-code editor developed by Microsoft. It serves as the primary development environment for the SmartConnect mobile application. With its extensive extension ecosystem—including the Flutter and Dart plugins—VS Code provides advanced features like IntelliSense, real-time debugging, and integrated terminal support. It facilitates a highly efficient development workflow, allowing for rapid code iteration through "Hot Reload" and seamless integration with version control systems like Git.

### 2. Android Studio (v2023.3.1+)
**Figure 2: Android Studio**  
Android Studio is the official Integrated Development Environment (IDE) for Android development. In this project, it is utilized for Android-specific configurations, managing Android Virtual Devices (Emulators), and building the final application packages (APKs). It provides comprehensive debugging tools and performance profilers that help in optimizing the app's resource usage. The integrated Gradle build system ensures that all dependencies and assets are correctly packaged for the Android ecosystem.

### 3. Firebase Console
**Figure 3: Firebase Console**  
The Firebase Console is a web-based platform used to manage and monitor the backend services of the SmartConnect application. It serves as the central hub for configuring Firebase Authentication, managing the Cloud Firestore database, and overseeing Cloud Messaging (FCM) for push notifications. The console allows developers to monitor real-time user activity, manage database security rules, and track app performance, providing essential tools for backend maintenance and scaling.

### 4. Jupyter Notebook (v7.0+)
**Figure 4: Jupyter Notebook**  
Jupyter Notebook is an open-source web application used for interactive computing. In this project, it is the primary tool for developing and testing the AI-driven matching models. It provides an environment where Python code, data visualizations, and explanatory text can be combined in a single document. It is used for data preprocessing, training machine learning algorithms, and validating matching accuracy before the models are deployed to the production environment via REST APIs.

### 5. Microsoft Excel
**Figure 5: Microsoft Excel**  
Microsoft Excel is a powerful spreadsheet application used for data organization and preliminary analysis. During the planning and research phases of SmartConnect, Excel is used to manage sample datasets, including worker skill sets and contractor requirements. Its built-in formulas and charting tools facilitate quick statistical summaries and data visualization, which inform the development of the matching logic and ensure the integrity of the data used for training AI models.
